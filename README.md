# StayMate 🏠

## Overview

StayMate is a cloud-based Android application developed as a Final Year Project to simplify the process of finding rental accommodations, PGs, and compatible roommates through a single platform.

The application connects tenants, property owners, and potential roommates while providing features such as property management, booking requests, and real-time communication.

## Features

### Tenant Module

* User Registration and Login
* Browse Available Properties
* Search and Filter Properties
* Save Favorite Properties
* View Property Details
* Book Properties
* Real-Time Chat with Property Owners
* Profile Management

### Owner Module

* Add New Properties
* Manage Property Listings
* Handle Booking Requests
* Chat with Tenants
* Update Profile Information

### Roommate Finder

* Create Roommate Posts
* Browse Roommate Listings
* View Roommate Details
* Connect with Potential Roommates

### Communication

* Real-Time Messaging
* Firebase Cloud Messaging (FCM) Notifications

## Technology Stack

* Java
* Android Studio
* Firebase Authentication
* Firebase Realtime Database
* Firebase Cloud Messaging (FCM)
* XML
* Cloudinary
